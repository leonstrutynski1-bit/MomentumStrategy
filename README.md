# Momentum Strategy — Finance & Quantitative Analysis

This repository contains a momentum strategy based on daily prices and volume of a chosen stock to see if we can beat long term passive investing with short to medium term active investing. This is a ongoing projet and part of my learning process as a quantitative finance student. 

> Note : I use official documentation, educational resources, and limited AI assistance to better understand Python concepts and debug my code. Since this is a learning project, I aim to implement and understand each component myself rather than use AI to generate the complete strategy. 

## Clarifications
A Python-based momentum strategy that :
- Retrieves market and financial data using yfinance
- Analyze daily prices and trading volumes
- Backtest the strategy
- Compare and evaluate its performance agaisnt passive buy-and-hold strategy 
- On going...

## Tools & Libraries Used
- Python  
- Pandas, NumPy  
- yfinance  
- Matplotlib
